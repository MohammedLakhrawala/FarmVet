    2. Focus on the affected area

    About the models and evaluation

    FarmVet uses separate MobileNetV2-based image classifiers for cattle and goats. Images are resized to 224 × 224 before inference.

    An independent labeled test set is not included in this project yet, so accuracy and per-class metrics are not reported.

    The repository includes MODEL_CARD.md and evaluate_models.py for documenting the models and evaluating them on a held-out test set.
